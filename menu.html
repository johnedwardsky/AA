Amber Avenue — Компонент меню

Нажмите кнопку ☰ в правой части хедера чтобы открыть меню.

На десктопе (≥ 901px) откроется мега-панель с тремя колонками.
На мобильном (≤ 900px) откроется полноэкранный ящик без нижних иконок и кнопки сравнения.

Что входит в компонент

  • Топ-застройщики — автоматически сортируются по рейтингу из AMBER_DATA.developers
  • Банеры — слайдер загружается из AMBER_DATA.menuBanners (или fallback на heroSlides)
  • Счётчики ЖК — рассчитываются из AMBER_DATA.properties
  • Районы — группируются по полю location в данных
  • Аккордеон для ЖК Калининграда и Полезное
  • Закрытие по ESC, клику вне панели и кнопке ✕
  • На мобиле: нет нижней навигации, нет кнопки сравнения
