## 1. Исполнительное резюме и SEO-концепция

Платформа **Amber Avenue** представляет собой специализированный экспертно-аналитический навигатор по первичному рынку недвижимости Калининградской области. Каталог портала объединяет **369 реально существующих и строящихся жилых комплексов**, сгруппированных по 4 ключевым макронаправлениям:
- **Калининград (Город):** 97 ЖК (Ленинградский, Центральный, Московский районы);
- **Побережье Балтийского моря (У моря):** 75 ЖК (Зеленоградск, Светлогорск, Пионерский, Янтарный);
- **Пригородный пояс (Пригород):** 139 ЖК (Гурьевск, Васильково, Ласкино, Холмогоровка, Большое Исаково, Орловка);
- **Города области (Область):** 58 ЖК (Балтийск, Гвардейск, Черняховск, Советск, Гусев, Полесск).

### Текущее состояние поисковой видимости и точки роста
На момент аудита сайт имеет высокий потенциал за счет качественного фронтенда, уникальной структуры данных (`properties-data.js`, `data.js`) и запатентованного рейтинга **Amber Index**. Однако органический трафик сдерживается рядом технико-семантических факторов:
1. **Дублирование метаданных:** Все региональные страницы направлений (`zhk-kaliningrad.html`, `zhk-umory.html`, `zhk-prigorod.html`, `zhk-oblast.html`, `zhk.html`) используют идентичный заголовок `<title>` и описание `<meta description>`.
2. **Отсутствие микроразметки Schema.org:** Ни на одной странице сайта не внедрены семантические JSON-LD сущности (`ApartmentComplex`, `BreadcrumbList`, `Organization`, `FAQPage`), что лишает сниппеты в выдаче звезд рейтинга, расширенных ответов и блоков цен.
3. **Структурные дефекты заголовков:** Наличие дублирующихся тегов `<h1>` на страницах хабов и попадание сырых интерполяционных строк `${p.name}` в статический HTML-код.
4. **Ограничения индексации динамического контента (CSR):** Динамический рендеринг карточек ЖК из JS-массивов требует точной настройки мета-тегов и карты сайта для гарантированной индексации всех 369 объектов поисковыми ботами Яндекс (YandexBot) и Google (Googlebot).

### Главная цель SEO-стратегии
Обеспечить доминирование Amber Avenue в поисковой выдаче Яндекса и Google по Калининградскому региону, а также среди межрегиональных покупателей (Москва, Санкт-Петербург, ХМАО, ЯНАО, Дальний Восток), за счет:
- 100% покрытия брендового спроса по всем 369 ЖК и 54 застройщикам;
- Захвата микролокационных и нишевых коммерческих запросов (автономное отопление, расстояние до моря, малоэтажные пригороды);
- Получения расширенных сниппетов (Rich Snippets) через валидную разметку Schema.org;
- Создания непревзойденного пользовательского опыта (User Experience) и высочайших поведенческих факторов (Time on Site > 3.5 мин, Bounce Rate < 25%).

## 3. Формулы и эталонные шаблоны On-Page мета-тегов и заголовков

### 3.1. Универсальная формула генерации мета-тегов

Для обеспечения идеальной уникальности, плотности ключевых слов и предотвращения санкций за дублирование разработаны алгоритмические формулы:

#### Формула `<title>`:
`[Основной ключ направления/страницы] [Год] — [УТП / Типы объектов / Локации] | Amber Avenue`  
*Длина: 60–75 символов (с пробелами)*.

#### Формула `<meta name="description">`:
`[Краткое позиционирование каталога/страницы]. [Количество объектов: 369 проверенных ЖК] в [Локациях]. [Ключевые фильтры: Автономное отопление, цены от застройщика, ипотека 6%]. [Рейтинг Amber Index и честные отзывы].`  
*Длина: 150–175 символов*.

#### Формула заголовков `<h1>` - `<h3>`:
- **`<h1>` (Строго один на страницу!):** Главный транзакционный запрос верхнего уровня.
- **`<h2>`:** Смысловые блоки, фильтры районов, преимущества локации, аналитика цен.
- **`<h3>`:** Названия конкретных жилых комплексов, имена девелоперов, карточки преимуществ.

/**

function updatePageMetadataForProperty(property) {
  const pageTitle = `${property.name} ${property.district} — Цены от ${property.price}, планировки, застройщик ${property.builder} | Amber Avenue`;

  document.title = pageTitle;
  
  // Обновление meta description
  let descTag = document.querySelector('meta[name="description"]');

### 4.7. Скрипт динамической инъекции Schema.org в DOM

Для автоматического формирования JSON-LD в single-page приложении при навигации:

```javascript
/**
 * Инъектор микроразметки Schema.org в <head> документа
 * @param {string} schemaId Уникальный ID тега script
 * @param {Object} schemaData JSON-LD объект
 */
function injectSchemaJsonLd(schemaId, schemaData) {
  let existingScript = document.getElementById(schemaId);
  if (existingScript) {
    existingScript.textContent = JSON.stringify(schemaData, null, 2);
  } else {
    const script = document.createElement('script');
    script.id = schemaId;
    script.type = 'application/ld+json';
    script.textContent = JSON.stringify(schemaData, null, 2);
    document.head.appendChild(script);
  }
}
```

### 5.5. Оптимизация индексации клиентского рендеринга (CSR/SSR/Prerender)

Поскольку карточки ЖК генерируются на стороне клиента через `properties-data.js`, для гарантированной индексации ботами:
1. **Pre-rendering статичного HTML-каркаса:** При генерации страниц в исходном HTML коде контейнер карточек должен содержать базовый список текстовых ссылок на топ-20 ЖК направления в виде `<noscript>` блока для краулеров без JS:
   ```html
   <noscript>
     <div class="seo-fallback-list">
       <h3>Популярные новостройки направления:</h3>
       <ul>
         <li><a href="zhk.html?id=1">ЖК «Рыбная деревня» (Калининград, СК КСТ)</a></li>
         <li><a href="zhk.html?id=2">ЖК «Русская Европа» (Калининград, АвангардИнвестПроект)</a></li>
       </ul>
     </div>
   </noscript>
   ```
2. **Скорость загрузки (Core Web Vitals):**
   - Все фоновые изображения (`kaliningrad_hero_new.jpg`, `baltic_sea_banner.png`) оптимизированы до формата WebP/AVIF.
   - Критические стили `style.css` предзагружаются (`rel="preload"`).
   - Показатель LCP (Largest Contentful Paint) удерживается в пределах **< 1.8 с**.

### 6.1. Матрица уязвимостей агрегаторов (Циан, Домклик, Этажи, Авито, Zastroyschiki39)

Федеральные платформы обладают гигантским ссылочным весом, но имеют критические системные слабости на локальном калининградском рынке:

| Критерий | Федеральные агрегаторы (Циан, Домклик, Этажи, Авито) | Региональные базы (Zastroyschiki39, RCN39) | Amber Avenue (Стратегическое превосходство) |
|---|---|---|---|
| **Актуальность и чистота базы** | До 30% «фантомных» объявлений риелторов, неактуальные цены-завлекаловки | Устаревшие на 6-12 месяцев данные о сроках сдачи | **100% верифицированная база 369 реальных ЖК** без риелторского спама |
| **Учет автономного отопления (АГО)** | Скрыто глубоко в параметрах квартиры или отсутствует | Отмечено в тексте без удобного фильтра | **Вынесено в главный бейдж карточки** + калькулятор экономии коммуналки |
| **Географическая специфика** | Формальный радиус в км без учета рельефа и транспорта | Общие описания | **Точный хронометраж:** пешком до моря / на «Ласточке» / на авто |
| **Оценка надежности** | Субъективные эмоциональные отзывы без верификации | Рейтинги отсутствуют | **Amber Index (1.0–10.0):** многофакторный независимый скоринг |
| **Пользовательский опыт (UX)** | Перегруженный интерфейс, всплывающие окна риелторов | Устаревший дизайн 2010-х годов | **Премиальный журнал-навигатор,** квиз подбора, адаптивность |
| **Rich Snippets в поиске** | Стандартные сниппеты листингов | Без микроразметки | **FAQ-аккордеоны, рейтинг звёзд,** микроразметка цен |
