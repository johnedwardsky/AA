# Спецификация подсистемы уведомлений и интеграций (Redis / BullMQ / Webhooks / Telegram)

**Проект:** Amber Avenue — Агрегатор новостроек Калининграда и курортного побережья Балтики  
**Версия спецификации:** 2.0.0 (Asynchronous Notification Architecture)  
**Очередь задач / Брокер:** Redis 7 + BullMQ 5  
**Каналы доставки:** Email (SMTP/API), Telegram Bot API, SMS Gateway, CRM Webhooks  
**Модель монетизации:** Включенные базовые каналы + Тарифные опции + Пакеты SMS

---

## 1. Архитектура асинхронного брокера (BullMQ Queues)

Подсистема нотификаций построена на базе очередей **BullMQ** в Redis, обеспечивающих гарантированную доставку (At-Least-Once Delivery), повторные попытки с экспоненциальной задержкой (Exponential Backoff) и приоритизацию задач.

```
                  ┌─────────────────────────────────────────┐
                  │          CORE EVENT DISPATCHER          │
                  │  lead.created • moderation.* • ads.*   │
                  └────────────────────┬────────────────────┘
                                       │
        ┌──────────────────┬───────────┴───────────┬──────────────────┐
        │                  │                       │                  │
        ▼                  ▼                       ▼                  ▼
┌───────────────┐  ┌───────────────┐       ┌───────────────┐  ┌───────────────┐
│  email-queue  │  │telegram-queue │       │   sms-queue   │  │ webhook-queue │
└───────┬───────┘  └───────┬───────┘       └───────┬───────┘  └───────┬───────┘
        │                  │                       │                  │
        ▼                  ▼                       ▼                  ▼
┌───────────────┐  ┌───────────────┐       ┌───────────────┐  ┌───────────────┐
│ SMTP / API    │  │ Telegram Bot  │       │ SMS.ru /      │  │ External CRM  │
│ (SendPulse)   │  │ (@AmberBot)   │       │ WebSMS API    │  │ (amo/Bitrix)  │
└───────────────┘  └───────────────┘       └───────────────┘  └───────────────┘
```

### 1.1 Параметры очередей BullMQ

| Очередь (Queue) | Concurrency | Retry Policy | Rate Limit | Назначение |
|---|:---:|---|---|---|
| `email-queue` | 10 workers | 5 попыток (Backoff: exponential, 5s, 15s, 60s, 300s) | 50 msg / сек | Транзакционные письма, отчеты |
| `telegram-queue` | 20 workers | 5 попыток (Backoff: 2s, 5s, 10s, 30s) | 30 msg / сек (Лимит Telegram API) | Мгновенные карточки лидов в чаты |
| `sms-queue` | 5 workers | 3 попытки (Backoff: 10s, 30s, 120s) | 10 msg / сек | Критические SMS и 2FA коды |
| `webhook-queue` | 15 workers | 8 попыток (Backoff: exponential с jitter, до 2 часов) | 100 req / мин на домен | Доставка лидов в CRM застройщиков |

### 2.2 Канал 2: Webhooks для внешних CRM-систем (amoCRM / Bitrix24 / Profitbase)

При создании лида сервер генерирует исходящий HTTP POST запрос на настроенный застройщиком URL (`developer_settings.webhook_lead_url`).

#### Заголовки безопасности Webhook:
- `Content-Type: application/json`
- `User-Agent: AmberAvenue-Webhook-Agent/2.0`
- `X-Amber-Timestamp: 1724610000`
- `X-Amber-Signature: sha256=d3b07384d113edec49eaa6238ad5ff00...` (HMAC-SHA256 от тела запроса с использованием `webhook_secret`).

#### Payload вебхука:
```json
{
  "event": "lead.created",
  "timestamp": "2026-08-25T18:30:00.000Z",
  "lead": {
    "id": "018e4f1a-bc23-74d1-9f12-000000000301",
    "legacyCode": "L-1724610000-842",
    "name": "Дмитрий Ковалев",
    "phone": "+79114509988",
    "email": "d.kovalev@example.com",
    "property": {
      "id": "018e4f1a-bc23-74d1-9f12-000000000010",
      "name": "ЖК «Балтийская Ривьера»"
    },
    "source": "card_cta",
    "details": "Интересует 2К квартира, этаж от 4-го",
    "utm": {
      "source": "yandex",
      "medium": "cpc",
      "campaign": "svetlogorsk_business"
    }
  }
}
```

### 2.3 Канал 3: Транзакционный Email

Письма отправляются в адаптивном HTML-формате с корпоративной стилистикой Amber Avenue (золотисто-янтарная палитра `#D97706`, `#B45309`).

#### Типы транзакционных писем:
1. `lead_notification`: Уведомление о новой заявке покупателя.
2. `moderation_approved`: Карточка ЖК успешно прошла модерацию и опубликована.
3. `moderation_corrections_required`: Замечания модератора по 9 табам с перечнем правок.
4. `placement_expiring`: Предупреждение об окончании рекламного слота за 7, 3 и 1 день.
5. `monthly_analytics_digest`: Ежемесячный дайджест показов, кликов и конверсии в PDF.
